# Step3：丝滑配比阀 —— 认识IEEE 754标准下的浮点数

## 任务3.1 ：
1. `float`使用32位，分别是1位符号位、8位阶码、23位尾数。
   `double`使用64位，分别是1位符号位、11位阶码、52位尾数。

2. 偏置值的公式为$Bias=2^{k-1}−1$，其中E为阶码值，e为实际指数，Bias是偏置值常数。这个公式保证了float中对于−126～127的指数，都可以以正数形式存储在计算机，从而避免了添加符号位。（float中Bias为127）

3. **非规格化数**：非规格化数是为了存储数值小于最小规格化数的数而设计的。特点就是允许隐含的1改为0，此时就可以突破最小的限制，把有效数字从1.M改为0.M，以表示更接近 0 的非零数，进而达到数值减小的效果。同时，由于为了存储更小的数，同时指数固定为最小的-126，阶码全为零用来标志非规格化数。

4. 特殊阶码规则：
    - 阶码全为 1 且尾数全为 0：表示无穷大，正负号依旧由符号位决定。
    - 阶码全为 1，尾数字段不全为 0：表示非数NaN，即不符合数学规律的运算中可能得到的结果（Not a number）。

# Step4：消失的营业额 —— 浮点加法、舍入与结合律

## 任务 4.1：设计加法程序

1. **对阶**
采用小阶向大阶看齐原因是如果将大阶数字的有效数字左移，会改变小数点左侧数字位数，从而不符合规格化数的形式。同时，小阶数字右移只会丢失对整体精度影响较小的末尾，而大阶数字左移时可能丢掉高位数字，对精度影响巨大。

2. **尾数运算**
对于本题限定的非负规格化数，存储的尾数字段省略了有效数字开头隐含的 1。在尾数运算时，应先恢复完整有效数字1.M，再对阶并相加，最后根据运算结果是否出现进位决定是否需要右规。

3. **规格化**
    - 左规操作：当尾数运算后结果的有效数字小数点左侧为0时，不符合规格化数要求1，因此将尾数左移至小数点左侧为1，同时阶码减去相应的值，得到数值相同的规格化数。
    - 右规操作：当尾数运算后结果的小数点左侧为10时，为了满足规格化数的要求，我们需要将有效数字右移直至小数点左侧为一，同时阶码加上1，得到数值相同的规格化数。

4. **舍入处理**
    - 向最近值舍入：选择距离原始值最近的可表示数
    - 向零舍入：直接丢弃多余位
    - 向正无穷舍入：选择可表示数中较大一种
    - 向负无穷舍入：选择可表示数中较小一种

5. **溢出判断**
即判断指数是否超出阶码可表示的范围，而四种分类分别对应浮点数为正负与指数过大或过小组成的四种情况。

```c

#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>

int trans(char input[]) {
	int value = 0;

	for (int i = 0;i <= 7;i++) {
		value = value * 2 + (input[i] - '0');
	}
	
	return value;
}

int function1(int x) {                         //求阶码
	x = x >> 3;
	x &= 15;
	return x;
}

int function2(int x) {
	x &= 7;                                    //求尾数
	return x;
}

int main() {
	char inputA[9], inputB[9];

	scanf("%8s %8s", inputA, inputB);

	int A = trans(inputA);                       //AB是十进制数
	int B = trans(inputB);

	int a = function1(A);                        //ab是阶码值
	int b = function1(B);

	int i = function2(A);                        //ij是尾数值
	int j = function2(B);

	int I = i | 8;                               //IJ是有效数字（乘以八）
	int J = j | 8;

	if (a <= b) {                                 //对阶
		I = I >> (b - a);
		a = b;
	}
	else {
		J = J >> (a - b);
		b = a;
	}

	int f = I + J;                               //尾数运算

	if (f >= 16) {
		f = f >> 1;
		a++;
	}

	int result = (a << 3) | (f & 7);

	for (int k = 7;k >= 0;k--) {
		printf("%d", (result >> k) & 1);
	}

	printf("\n");

	return 0;

}
```

## 任务 4.2：老板为什么每天都在亏钱？
浮点数运算时，因为10^20与15在二进制下指数不同，因此小阶向大阶对齐时，15的有效数字会非常小，而这个数字会被舍去，无法保留在有限的精度中。在整个计算中，如果两个大数先做运算就可以避免对小数的影响，而大数和小数直接运算时就会导致大数吸收，即小数因精度有限而丢失。
